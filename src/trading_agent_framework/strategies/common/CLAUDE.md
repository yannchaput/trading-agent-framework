# strategies/common/ -- code shared between strategies

> Nested `CLAUDE.md`; project-wide rules are in the root `CLAUDE.md`. Paths are relative to `src/trading_agent_framework/` unless they start with `tests/`, `scripts/` or `docs/`.

## Architecture

- `strategies/common/` -- code shared between strategies, imported from there (no re-export shims; docs under `docs/superpowers/` still name the old locations): `scoring.py` (**pure** momentum scoring moved from cross_momentum: `compute_return_from_prices`, `annualized_volatility`, `momentum_score`, `apply_filters`, `momentum_inputs`, then `score_stock` -> `MomentumRow` (`None` when filtered out or without a volatility, which cross_momentum would still rank but bull_bear cannot size) and `rank` -> `RankedRow`), `rebalancer.py` (`Rebalancer`, moved from bill_ackman, typed against the `RebalanceParams` protocol: `parking_symbol`, `rebalance_band`, `min_trade_pct`, `cash_buffer`; sells first, then buys, then SHV; **the cash invariant**: the account is read ONCE, before positions, open orders and any order, `cash` is never read again, and sell proceeds are added to that pre-sell snapshot, so a sell of this run that fills within seconds is counted once, and an earlier sell that has already filled (proceeds in the snapshot, no longer open) is not credited again -- reading the account afterwards double-counted it, the congress_trades (275c2f3) and earnings_drift (c652426) bugs; `buying_power` is re-read after the sells but only inside `min()`. The invariant does NOT cover an earlier open BUY that fills between the account read and the open-order read (its cost leaves `incoming` while the snapshot still holds the pre-fill cash); the `buying_power` re-read inside `min()` bounds that on a cash account only; pinned by two live-fill tests in `tests/strategies/common/test_common_rebalancer.py`), `portfolio.py` (**pure** `TargetPortfolio`, `target_portfolio`), `sessions.py` (**pure** `completed_bars`, `parse_rebalance_time`), `yahoo_daily_bars.py` (`YahooDailyBars`, the one batched Yahoo download of paper/live daily bars), `sector_provider.py` (`SectorProvider`: yfinance sectors cached per instance, `"UNKNOWN"` on any failure, not point-in-time). Used by cross_momentum, bill_ackman and bull_bear.
