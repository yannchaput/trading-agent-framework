# fundamentals/ -- SEC EDGAR client

> Nested `CLAUDE.md`; project-wide rules are in the root `CLAUDE.md`. Paths are relative to `src/trading_agent_framework/` unless they start with `tests/`, `scripts/` or `docs/`.

## Architecture

- `fundamentals/` -- SEC EDGAR client, trimmed and ported from lumibot's `SECFundamentals`: `sec.py` (**pure**: tag maps, as-of candidate filtering, statement-period matching, filings parsing, URL building, HTML stripping, `parse_dt`, `older_pages` (the older submission pages reaching back to a date, shared by earnings_drift and insider_trades), `raw_form4_document` (a Form 4's raw XML name, not the `xslF345X05/` rendering); bill_ackman's screen imports `INCOME_STATEMENT_TAGS["revenue"]`/`["operating_income"]`, `BALANCE_SHEET_TAGS["cash"]`, `CASH_FLOW_TAGS` and `total_debt_sources` (the one definition of total debt: total tags, then noncurrent + current, then the combined tag) and those must not change without bumping its `SCHEMA_VERSION`, so filers of 20-F / 40-F reports (IFRS: Abivax, Kinross, UMC, ...), whose facts sit under `ifrs-full`, have their own `IFRS_INCOME_STATEMENT_TAGS`/`IFRS_BALANCE_SHEET_TAGS`, read by `statement_values(..., ifrs_tag_map=)` and `compact_company_facts` for the agent tools only: candidates of both taxonomies compete and the most recently filed wins, and the `unit` field carries the reporting currency, labelled and never converted) and `edgar_client.py` (`SecEdgarClient`, the only module allowed to import `httpx` for SEC access -- cached to `<project_root>/cache/sec/`, rate-limited, requires `SEC_EDGAR_USER_AGENT`; `fetch_json` is its uncached path and HTTP 404 raises `FundamentalsNotFoundError`; the cached payload getters take optional `as_of` and `max_age_days` (default `freshness.DEFAULT_MAX_AGE_DAYS` = 1 day, the one framework default, so the drill-down tools pass none), so a payload older than max_age_days by the strategy clock is fetched again -- a backtest never refetches an existing file, live refreshes daily; an explicit value is kept (earnings_drift and insider_trades pass 0) and bill_ackman's screen (its own annual store and `max_age_days`, the uncached `fetch_*` paths) is unaffected; `default_client(project_root)` builds the client from `SEC_EDGAR_USER_AGENT`, caching to `<project_root>/cache/sec`), plus `freshness.py` (`is_stale`, the cache-age rule); `get_submissions_page(name)` reads an older submissions page and caches it for good, since it never changes. The quality screen built on it lives in `strategies/bill_ackman/screen/`. The agent statements are `sec.balance_sheet` (a US GAAP filer's `debt` is `total_debt` (10-K, 10-Q and 20-F/40-F rows, in the statement's reporting currency), never a current portion; an IFRS filer's is `Borrowings`) and `sec.income_statement` (adds `operating_cash_flow`, `capex`, `free_cash_flow`); every value carries its period (`start` for a flow, `end`) and `prior_year`, the same-length period about a year earlier, so a 10-Q quarter is never paired with a year-to-date figure; the tools add `stale: true` when the newest period ended more than 548 days before `as_of`.
